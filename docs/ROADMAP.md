# 当前进度与后续方向

更新：2026-09-07。本地首版 v1.0.0 以四机体、八分钟双 Boss、工坊与专精矩阵为基线。当前参数见 [强度记录](BALANCE_AUDIT.md)，验收见 [首版记录](LOCAL_V1.md)。

## 当前完成

- 首版后更新：环绕卫星/星系引擎新增碰撞减伤、盾量×5×角色等级固定反伤及破盾免溢伤；震荡盾盘增强盾面与扇形冲击表现。常规出怪起点提高至 2/秒，以平滑曲线衔接旧终盘期望 4.643/秒，详见 README。

- 焰锋：15 格储存、空格 15 秒超载、共享 2 秒计热间隔；常态与超载独立灼烧，专属时长 ×1.5 纯加强，脚下火苗五层外观封顶。
- 磁暴：三发满仓聚能，严格消费储能、进化保持蓄力进度。
- 铁壁：实际盾伤积累震荡，与盾盘强化分开；低级盾盘无击退。
- 霜翎：周期防反与一发储备，穿透冰爆对每目标最多三次结算。
- 工程：去除失效爆燃路径与无用绑定；同帧宝箱、经验拆分、烧死接触、四选一布局、保存失败与重试已覆盖回归；保留所有存档 ID。

## 后续顺序

1. 以本地 Git 基线做完整八分钟实战记录，比较零/满工坊、各难度的击杀时间、受击和技能使用时机。焰锋本次 ×1.5 是明确要求的纯加强，不因为木桩数字较高而自动削弱其它参数。
2. 打磨角色各自的操作回报：焰锋何时开超载、磁暴紧急单发与满仓选择、铁壁回盾解围、霜翎窗口辨识。后续多人物变更继续统一实现、测试与交付。
3. 补存档导入/导出、音乐/音效独立音量和震屏设置；当前写入失败会提示，待保存结算仅保留在本页。
4. 再推进分享试玩与服务器发布。域名、HTTPS、更新回滚见 [部署说明](DEPLOY.md)。当前无账号、云同步和触屏移动。

新增人物、武器进化与 Boss 放在现有节奏验证之后。引力操控机、裂镜审判者、铸城者仍为远期备选，尚未实现或排期。新增 Boss 可先替换现有时段，不同时拉长单局。
