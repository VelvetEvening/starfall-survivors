# 当前游戏机制

更新日期：2026-11-08
适用范围：v2.0 正式静态游戏与同产物的本地离线版；服务器共享规则的对应实现仍需独立验收与发布。

## 1. 技术与单局流程

- 原生 JavaScript + Canvas 2D，运行时零包依赖；音频由 WebAudio 合成。
- 逻辑坐标固定为 480×270，显示缓冲可按窗口和像素密度放大；渲染倍率不改变碰撞、射程、移动和数值。
- 一局倒计时 8 分钟：4:00 进入 BOSS1，8:00 进入 BOSS2；击杀最终 BOSS 胜利，死亡或其它结束条件进入结算。
- 主循环使用固定 1/60 步长；输入在逻辑步末消费，暂停、升级、星图等面板状态暂停战斗资源更新。
- 常规武器自动攻击；电磁炮由鼠标点击瞄准发射。当前正式支持电脑键盘和鼠标，小窗口适配不等于触屏支持。

## 2. 目录到机制的映射

- src/data/ 是策划表：角色、武器、被动、敌人/BOSS 攻击和配置常量。
- src/sim/ 执行投射物、武器、敌人、BOSS、波次和掉落；src/growth/ 聚合玩家属性、升级和专精矩阵。
- src/engine/game.js 管理状态机、时间、经验、结算和局内事件；src/ui/ 只处理面板与反馈；src/render/ 只负责表现层。
- src/core/save.js 是唯一持久化出口。当前实现是 LocalStorage；线上化时替换为带 Session 的 ServerLayer，不能在 UI 或战斗代码中另写存档。

## 3. 三机体

可选角色为焰锋、霜翎、磁暴；内部 ID vega、firefly、thunder 保持不变。铁壁及其武器、材料和壁垒矩阵退出当前内容池；历史 dawn 存档保留作迁移凭据。

- 焰锋：全火系共享计热，达到 15 格后按空格开启 15 秒超载；超载期间不计热，常态与超载灼烧独立叠层。
- 霜翎：开局就绪，空格主动开启严格 0.2 秒防反，冷却从按下时起算，基础 20 秒，新增霜息回流/瞬凝回路各减 3 秒至最低 14 秒；按住不重复释放。窗口不受任何延时影响，防反冷却只读取矩阵专用效果，不受装备、普通无敌或普通冷却缩减影响。窗口内免伤，最多触发一次反制冰域，并准备下一发强化霜棱弹。冰系命中可叠冰蚀；BOSS 不被冻结。
- 磁暴：电磁炮普通单发与满仓三发聚能有专属倍率；一次点击严格消耗一发或满仓，停滞期间不缓存点击。

霜翎原来的两个延时节点改为冰系范围 +5% 和反制冰域伤害 +15%，内部节点键保留。停滞期间不能开启或缓存技能；暂停冻结窗口与冷却。死亡、重开清理技能状态。当前回归证据见 V2_ACCEPTANCE.md 与 gui-test-screenshots/v2.0/。

新增霜息回流与瞬凝回路各减 3 秒防反冷却，分别接在霜裂刻痕和反制增幅后，保留旧节点效果并重排路线。沿防反路线累计投入 9/18 点时分别降到 17/14 秒，无须先点复活节点；极寒重启留在两支汇合的终点。技能就绪时机体周围出现六瓣冰晶与淡辉光；使用后进入冷却，提示消失。删除原头顶进度小圈，底部 HUD 仍显示冷却。防反成功有贴身碎冰冲击和攻击者处的冰域裂纹，保持原伤害与控制次数。

## 4. 武器、升级与专精

- 武器通过自动攻击、冷却、蓄力、穿透、灼烧、冻结、冰蚀和进化构成 Build；武器升级和进化不能让每发伤害或全命中 DPS 倒退。
- 升级三选一在升级面板完成；宝箱优先进化，无法进化时给一次升级选择并增加专精点。同帧获得经验时，进化完成后继续处理排队的升级，再恢复战斗。
- 三条专精矩阵各 8 节点、本系总成本 30；本系消耗乘 1，异系消耗乘 2。矩阵效果先聚合，再由 player.recalcStats 结算派生属性。
- 持有对应超武后，被动联动效果会追溯已获得层数；进化后必须重新计算派生属性。
- 装甲工坊为局外强化：生命、速度、伤害各 5 级，初始武器购买 5 次后按 Lv.6 入场；旧档 ID 和 weapon=5 语义保持兼容。
- 现有 6 把基础武器、6 种进化、6 件被动，火冰雷各两条路线。移除环绕卫星、星系引擎、震荡盾盘与引力透镜；场上的磁铁补给保留。
- 霜棱弹 Lv.6 + 冰晶棱核 Lv.3 → 极寒贯星：定向贯穿冰枪，常态每发对每目标最多一次伤害与控制，防反强化发最多三次；命中次数按整发弹体共享。进化保留防反强化，原武器不再进入新武器池。冰晶棱核增加冰伤和冰弹速度，持有对应超武后效果 ×1.5，不影响防反窗口。
- 激光锁定最近敌人后短时扫射，间歇后重新瞄准；光谱裁决只保留一束高压电流，原主副束理论直伤合并到单次 tick，不再有分叉伤害路径。导弹灼烧不再抵消冰伤、冰控或冰蚀。
- 激光与电磁炮均增加跳动电弧和命中放电：光谱是单轴宽电流，电磁炮是电弧包裹的穿甲弹，天罚为贯穿电流通道。磁暴的侧条、横向电流与头顶存弹小点已移除，改用机体周围缓慢环绕的短电弧：普通就绪两段，满三层三段并增强亮度；空仓、停滞或死亡不显示。存弹数量由底部仪表显示，减少动态效果模式使用静止电弧。天罚普通光束显示 0.3 秒，磁暴满三层聚能显示 0.75 秒（2.5 倍）；伤害只在发射瞬间对每敌结算一次，余辉没有持续碰撞。装饰电弧不追加伤害，也不消费战斗随机数。
- 材料卡独立显示进化材料图标与标签，元素图标继续说明实际增益类型。
- 热能核心实际增强火系直伤和灼烧时长，聚束晶体增强雷伤和雷系范围。升级卡以火、冰、雷图标标记实际收益；弱点分析保留通用标记，选中时另列进化配方。
- 宝箱、磁铁、血包拾取半径分别为 15、13、13 逻辑单位，包含边界，使用移动线段判定避免高速越过漏拾取。星尘拾取半径仍为 7；经验吸引半径与上述补给拾取判定独立。

## 5. 敌人和 BOSS

- 常规出怪从玩家附近生成，频率随时间按平滑曲线变化；精英在固定时间点出现并提供宝箱/高价值星尘。
- BOSS1 与 BOSS2 的召唤技能只在自身边缘生成召唤精英，不夹带普通小怪；同屏召唤精英有上限。
- BOSS 战另外由波次导演每 30 秒从玩家四周生成环境小怪：BOSS1 每波 15 只，BOSS2 每波 20 只。这些实体带 noRewards，死亡不产经验、道具、分数，也不计击杀统计；分裂实体必须继承该标记。
- BOSS1 存活时小怪血量停在第一段曲线终点；击杀事件触发后才跳升，不能用浮点计时是否略超 240 秒代替击杀状态。
- BOSS2 50% 血量进入狂怒二阶段，二阶段技能按 phase2Only 过滤；转阶段首次释放深渊停滞。BOSS 不冻结，减速只部分生效，灼烧仍可生效。
- 接触伤害、敌弹、冰冻易伤、冰蚀和角色防反都在实体伤害收口处保持明确的免疫/乘区语义。

## 6. 反馈与表现约定

- 顶部 toast 只显示 BOSS、精英和怪潮警告；系统内提示使用音效、粒子、HUD 或面板。
- 普通小怪弹为红色，精英/BOSS 高危弹为金色，BOSS2 高伤或强化精英弹为深暗红；颜色必须和实际伤害等级一致。
- 世界层绘制使用 renderer 坐标 helper，绘制 UI 前切换到 R.beginUI()；粒子统一由粒子模块进行世界到屏幕换算。
- 状态视觉必须与机制一致：不吃冻结的实体不得画冻结效果，BOSS 受折扣减速时显示淡冰圈。
- 隐去普通伤害数字、重复停滞和磁铁文字；HUD 保留生命、经验、武器和紧凑的技能就绪/冷却提示。危险预警、受伤和治疗等必要反馈保留。
- 新增特效遵守减少动态效果偏好：就绪冰晶保持静态，成功冲击减少位移且不震屏，光束保留真实扫射而关闭装饰脉冲运动。暂停不推进这些视觉状态。

## 7. 存档与线上拆分边界

本地版的 localStorage 只适合单机试玩，不能提供跨设备同步、可信排行榜或防作弊。线上版本必须把身份、资产、对局结算和排行迁移到服务器；客户端可以预测表现，但不能覆盖服务器快照。

最高分按难度分桶保存。仅缺少 bestScores 的旧档会把 bestScore 迁入正常难度；新档的 bestScore 是跨难度兼容字段，重载不得覆盖正常难度纪录。已被旧逻辑串改的历史纪录缺少原始分数，不能自动还原。

v2 使用 schemaVersion=2：旧档按铁壁各项已购买等级对应的实际阶梯费用一次性返还星尘；保留历史加点，不再显示或接受铁壁购买。迁移与下一次正常保存一同落盘，重复保存/重载不得重复返还。服务器对应迁移为 005_v2_retire_dawn.sql，仅测试过隔离数据库，未执行生产迁移。

线上实施顺序、账号安全、WebSocket、确定性模拟和发布验收见仓库外层 ONLINE_ROADMAP.md。
