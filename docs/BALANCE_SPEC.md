# 当前平衡规格

更新日期：2026-09-08
定位：当前数值设计的可读规格；实际执行值以 src/data/config.js、weapons.js、passives.js、characters.js、enemies.js 为最终来源。

## 1. 难度与小怪质量

三档小怪均从 ×3 开局，使用两段 smoothstep；BOSS1 击杀保留一次离散质量跳跃。终点与第一段锚点如下：

| 难度 | 开局 | BOSS1 前段终点 | 击杀后跳点 | 8:00 终点 |
|---|---:|---:|---:|---:|
| 简单 | ×3 | ×10.463 | ×17.352 | ×29.58 |
| 正常 | ×3 | ×12.539 | ×21.345 | ×36.975 |
| 困难 | ×3 | ×16 | ×28 | ×49.3 |

普通小怪和野生精英不额外乘难度 hpMul；BOSS 与固定倍率召唤精英保留难度生命倍率。小怪接触伤害每分钟 +12%，BOSS1 击杀后再整体跳升；精英伤害在首杀后提升 25%。

## 2. 出怪、精英与 BOSS

- 常规出怪：SPAWN_RATE_START=2，终点保留 1.3/0.28 的旧终盘频率口径，使用 smoothstep；同屏上限 160。
- 环形怪潮：每 90 秒一次；BOSS 战常规出怪暂停。
- 野生精英血量：小怪曲线乘 ELITE_HP_FACTOR=0.78；流程内 5 个时间点出现。
- BOSS 召唤精英：BOSS1 固定倍率 10，BOSS2 固定倍率 15，召唤数量和倍率均由数据表控制；同屏上限 8；召唤点在 BOSS 边缘。
- BOSS 环境波次：间隔 30 秒，BOSS1 每波 15 只，BOSS2 每波 20 只，半径 320，全部 noRewards。
- BOSS 基础血量：BOSS1 12000，BOSS2 24000；当前困难/正常/简单的 BOSS hpMul 仍为 1.25/1/0.75。
- 冲撞技能基础冷却：BOSS1 激光 6.4 秒，BOSS2 二阶段冲撞弹幕 8 秒；BOSS2 50% 血量进入狂怒阶段。

## 3. 伤害颜色梯度

正常难度终盘的目标梯度为：普通小怪红弹约 28 < 精英/BOSS 金弹约 32.5 < 强化金弹 52 < 深暗红弹 56。新增弹幕或改动伤害后必须运行 node tools/verify_fixes.js，避免颜色语义与数值倒挂。

## 4. 武器与进化基准

以下为满级基准直伤 DPS，不含角色、暴击、共鸣和灼烧；持续贴身或全命中理论值必须结合武器定位阅读：

| 武器/进化 | DPS |
|---|---:|
| 环绕卫星 / 星系引擎 | 240 / 977 |
| 激光扫射 / 光谱裁决主束 | 111 / 208 |
| 脉冲飞刃 / 量子棱镜 | 38.2 / 262.6 |
| 爆裂导弹 / 轨道天火 | 34.5 / 116.5 |
| 冰霜新星 / 绝对零度 | 24.6 / 39.2 |
| 霜棱弹 | 31.5 |
| 超电磁炮 / 天罚电磁炮 | 30 / 90 |
| 震荡盾盘 | 50.9 |

火系常态间隔乘 1.5，导弹固有倍率保留；焰锋超载用乘 0.8 替换常态间隔。天罚电磁炮每敌每炮 540 伤害、蓄力约 6 秒，光束宽度为 22→26；Lv.1 与超电磁炮 Lv.6 的 22px 弹体直径对齐。磁暴满仓聚能统一使用 ×3.3 伤害、×1.25 尺寸；蓄力缩减统一经 chargeDuration 计算。

## 5. 被动、护盾和角色成长

- 基础被动档：暴击 +3.5%/层、暴伤 +7.5%/层、减伤 +1/层、移速 +3.5/层、拾取 +4.5/层、护盾为入场生命 5%/层；持有对应超武后该被动每层乘 1.5，并追溯已有层数。
- 超频芯片只减少蓄力时间，不再减少普通冷却；磁暴的 chargeMul 与 chargeRed 乘算。
- 护盾上限 10；铁壁每 10 秒回复 5 点。铁壁震荡阈值 12，冷却 1.2 秒，半径 86，基础伤害 28，击退 72。
- 全角色基础生命已乘 0.8；工坊生命强化按基础生命百分比每级 +10%，最多 5 级。
- 霜翎周期防反基础 0.5 秒，矩阵当前合计 0.8 秒，硬上限 1 秒；冰冻易伤小怪乘 1.2（5 秒），BOSS 免疫；冰蚀最多 3 层，每层承伤乘 1.1，BOSS 可受冰蚀。

## 6. 经验、奖励与兼容性

- 星尘按 def.xp 足额拆分，单次最多 14 颗；BOSS 的 200/600 经验不能用颗数上限截断。
- BOSS 战环境小怪完全无收益；BOSS 召唤精英按召唤变体规则处理，不掉宝箱，防止刷收益。
- 工坊生命/速度/伤害各 5 级，初始武器购买 5 次后按 Lv.6 入场；旧存档 weapon=5 必须可读。
- 角色、武器、专精节点和存档内部 ID 不能随显示文案改名；线上资产迁移必须使用显式版本号。
